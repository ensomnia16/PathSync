# 路径同步 / PathSync

轻量 macOS 文件夹同步工具。适合在本地频繁编译 LaTeX 等会产生大量小文件的项目，再按较长间隔同步到 OneDrive 或其他已挂载的目标目录。

## 下载

[下载 Apple Silicon 版应用](https://github.com/ensomnia16/PathSync/releases/tag/v2.2.0)（macOS 13+）。下载包未经过 Apple 公证；也可按下文在本机从源码构建。

## 功能

- 添加多组本地目录和目标目录；每组可独立启用、命名和设置定时模式。
- 定时双向合并：一侧更新就复制到另一侧；同一文件两侧都改过时保留两份原件并报告冲突。
- 手动执行双向合并、本地 → 目标、目标 → 本地，或按各组设定同步所有已启用路径。
- 默认每晚 23:00 运行；也可设置 6–168 小时的间隔。
- 不删除另一端文件；跳过更晚更新的目标文件。默认过滤 LaTeX 中间文件、虚拟环境和缓存。
- 目标 → 本地逐文件处理；某个云端占位文件读取失败时，继续处理其他文件，并记录到日志。

首次双向合并遇到同名且内容不同的文件时不会猜测哪份正确，会报告冲突。双向模式不传播删除；单侧缺失的文件会从另一侧恢复。成功处理的文件状态保存在 `~/Library/Application Support/ResearchSync/merge-state/`，后续只检查有变化的文件。每次运行按路径组记录上传、下载、冲突和失败数量。

建议先让云盘客户端下载需要的文件，再使用“目标 → 本地”。工具不能替代云盘客户端获取尚未下载的占位文件内容。

## 构建

需要 macOS 13 或更新版本、Xcode Command Line Tools。运行：

```sh
./build.sh
```

生成的应用位于 `.build/路径同步.app`。复制到 `/Applications` 后打开，在应用中选择目录并点击“保存设置”。定时任务以当前登录用户身份通过 `launchd` 运行；无需管理员权限运行同步。

## 命令行

应用包中的 `Contents/MacOS/ResearchSync` 支持：

```text
--sync                  按每组保存的方向同步所有已启用路径
--push                  所有已启用路径：本地 → 目标
--pull                  所有已启用路径：目标 → 本地
--merge                 所有已启用路径：双向合并
--dry-run               预览，不复制
--pair UUID             只运行指定路径组
--config PATH           读取指定配置文件
--install               安装或更新当前用户的定时任务
```

配置和日志保存在 `~/Library/Application Support/ResearchSync/`，定时任务位于 `~/Library/LaunchAgents/com.ensom.ResearchSync.plist`。应用保留内部标识 `ResearchSync`，以便从旧版本迁移配置。

## 同步规则

双向合并使用上一次成功处理的文件状态判断哪侧更新，并在复制前后检查源和目标是否又发生变化。本地 → 目标使用 macOS 自带 `rsync` 的 `--update`，目标 → 本地使用随应用打包的 Python 文件复制器。所有模式都不会执行删除。手动同步所选路径可在保存该路径前运行；后台任务只读取已保存的配置。首次使用前请核对路径和定时模式。

如果 OneDrive 等云盘文件提供程序返回 `Operation timed out`，表示本次未能读到该文件内容；检查云盘客户端下载状态后重试。日志会记录失败文件。
