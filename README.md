# 路径同步 / PathSync

轻量 macOS 文件夹同步工具。适合在本地频繁编译 LaTeX 等会产生大量小文件的项目，再按较长间隔同步到 OneDrive 或其他已挂载的目标目录。

## 下载

[下载 Apple Silicon 版应用](https://github.com/ensomnia16/PathSync/releases/tag/v2.5.0)（macOS 13+）。下载包未经过 Apple 公证；也可按下文在本机从源码构建。

## 功能

- 添加多组本地目录和目标目录；每组可独立启用、命名和设置定时同步方向。
- 定时双向合并：一侧更新就复制到另一侧；发现不同版本时暂停该文件，并在界面中列出待处理冲突。
- 冲突可选择本地版本、云端版本或保留两份。处理前先把两侧原件备份到本机；文件在选择后发生变化会拒绝覆盖。
- 手动执行双向合并、本地 → 目标、目标 → 本地，或按各组设定同步所有已启用路径。
- “默认计划”独立入口：可选择每天的任意同步时间，或设置 6–168 小时的间隔；所有已启用路径共用此计划，各路径可单独选择方向。
- 界面支持简体中文、英文和跟随系统语言；应用名称也会随系统语言显示。
- 界面采用 SwiftUI 原生侧栏、分组表单、系统控件与工具栏；蓝釉图标用单轴双向箭头表示路径往返。
- 不删除另一端文件；三个同步方向共用变更基线，单向同步也不会静默覆盖已变化的目标文件。默认过滤 LaTeX 中间文件、虚拟环境和缓存。
- 逐文件处理；某个云端占位文件读取失败时，继续处理其他文件，并记录到日志。

首次同步遇到同名且内容不同的文件时不会猜测哪份正确。冲突会保存在 `~/Library/Application Support/ResearchSync/merge-state/`，打开应用后进入对应路径组，可在 Finder 中查看两份文件，再选择处理方式。“保留两份”以本地版本作为原路径文件，并把云端版本另存为带 `cloud conflict` 标记的文件；两个版本都会出现在两侧。处理前保存的原件也留在 `merge-state/<路径组 ID>-conflict-backups/`。双向模式不传播删除；单侧缺失的文件会从另一侧恢复。每次运行按路径组记录上传、下载、冲突和失败数量。

建议先让云盘客户端下载需要的文件，再使用“目标 → 本地”。工具不能替代云盘客户端获取尚未下载的占位文件内容。

## 构建

需要 macOS 13 或更新版本、Xcode Command Line Tools。运行：

```sh
./build.sh
```

生成的应用位于 `.build/路径同步.app`。复制到 `/Applications` 后打开，在应用中选择目录并点击“保存设置”。定时任务以当前登录用户身份通过 `launchd` 运行；无需管理员权限运行同步。

当前图标源图是 `PathSyncIcon.png`，由选定的“轨道梭”方案直接生成；旧版 `GenerateIcon.swift` 仅保留作历史参考。应用内“关于”页面可以选择界面语言。

## 命令行

应用包中的 `Contents/MacOS/ResearchSync` 支持：

```text
--sync                  按每组保存的方向同步所有已启用路径
--push                  所有已启用路径：本地 → 目标
--pull                  所有已启用路径：目标 → 本地
--merge                 所有已启用路径：双向合并
--dry-run               预览，不复制
--pair UUID             只运行指定路径组
--config PATH           读取指定配置文件
--resolve RELATIVE_PATH --choice local|cloud|both --pair UUID
                       处理指定路径组中的一个待处理冲突
--install               安装或更新当前用户的定时任务
```

配置和日志保存在 `~/Library/Application Support/ResearchSync/`，定时任务位于 `~/Library/LaunchAgents/com.ensom.ResearchSync.plist`。应用保留内部标识 `ResearchSync`，以便从旧版本迁移配置。

## 同步规则

三个方向使用同一份上次成功处理的文件状态判断哪侧更新；对不同版本不按时间戳猜测赢家。复制和冲突处理前会检查文件是否又发生变化。冲突处理时首先在本地保存并校验两侧原件，然后才更新同步路径。所有模式都不会执行删除。手动同步所选路径可在保存该路径前运行；后台任务只读取已保存的配置。首次使用前请核对路径和定时模式。

如果 OneDrive 等云盘文件提供程序返回 `Operation timed out`，表示本次未能读到该文件内容；检查云盘客户端下载状态后重试。日志会记录失败文件。
